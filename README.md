# ASL Conformance Kit

This repository contains public conformance artifacts for the Agent Safety Layer (ASL). It is intentionally separate from the ASL implementation repository and does not include the ASL source tree or test suite.

## Verify the conformance vectors

Requires Python 3.11 or later. The verifier uses only the Python standard library:

```bash
python conformance/verify_vectors.py
```

Expected output for the artifacts in this revision:

```text
checked 45 vector cases, 0 failures
receipts: 0 Ed25519-verified against the published key, 5 v1 HMAC-only and not publicly verifiable, 0 failures
```

The verifier fails closed rather than reporting a quiet pass: it exits non-zero unless it checked exactly 45 vector cases (a `sys.exit`, not an `assert`, so `python -O` cannot remove the gate), treats a malformed, non-object, unknown-family or unreadable vector file as an error instead of skipping it, and treats a bad Ed25519 signature, a stripped `receipt_format_version`, an unknown key id or a missing published key as a failure.

This command verifies the language-neutral fixtures in `conformance/vectors/` and the signatures on the receipts in `conformance/benchmarks/receipts/`. It does **not** rerun the ASL test suite, regenerate the reports, or independently reproduce the benchmark and gate measurements described by the bundled reports.

## Repository contents

- `conformance/vectors/` — canonicalization, hashing, token, audit-chain, attestation and boundary protocol fixtures. The canonicalization cases specify the ordering, number and escaping rules the ASL canonicalizer is tested against; they are not a claim of RFC 8785 conformance. Test keys in these fixtures are explicitly fake and are not production credentials.
- `conformance/verify_vectors.py` — standalone standard-library verifier for those fixtures and for `v2` receipts. It does not import ASL; its Ed25519 is an independent RFC 8032 implementation.
- `conformance/verifier_public_key.json` — the published Ed25519 verification key (key id `8c889c63bb02e676`). Its private half is not published and is not in this repository.
- `conformance/benchmarks/` — public benchmark payload bundles and associated receipts.
- `docs/` — copies of selected ASL reports and documentation: the public benchmark report, invariants, limits and threat model.
- `scripts/check_conformance_drift.py` — compares the specification files in `conformance/` against the helper revision named in `SOURCE_COMMIT` and exits 1 on drift.
- `LICENSE`, `SECURITY.md`, `SOURCE_COMMIT` and `.github/workflows/ci.yml` — the kit's own license, advisory contact, the helper commit it mirrors, and the job that runs the verifier on `push` and `pull_request`.

The signed evidence report, boundary/ceiling receipt, and kernel-confinement notes are not published in this revision. They were withdrawn on 2026-10-30 pending regeneration; no containment-level or completeness claim is made here.

The ASL implementation, its test suite, evidence-generation scripts, and raw gate inputs belong in the [ASL source repository](https://github.com/Raja549h/helper), not in this kit. This repository’s reports and documentation may refer to those external implementation files to identify how a claim was tested; those links do not mean the files are included here.

## Important limits on report verification

The five bundled benchmark receipts are **v1 HMAC-SHA256**. HMAC uses a shared secret, so those signatures cannot be authenticated by a reader of this kit; the verifier says so instead of pretending to check them. A **v2** receipt (`receipt_format_version: 2` with a `receipt_ed25519` field) *is* publicly verifiable here, against `conformance/verifier_public_key.json`, and its public signature covers the HMAC body too — but no v2 receipt is published in this revision. Do not treat the bundled HMAC values as publicly verifiable signatures or as independent certification.

The reports are snapshots copied from the ASL project. Their measurements are not regenerated by this kit, and this repository does not contain all raw inputs needed to reproduce every reported number. Consult the linked source repository and the evidence artifacts for the corresponding revision (`SOURCE_COMMIT`) before relying on a measurement.

## Scope

This kit is a protocol-fixture and report-publication repository, not a distributable ASL implementation, a complete test environment, or an independent security assessment. It contains no ASL source or tests. Reviewers should distinguish vector conformance (which can be checked here) from implementation behavior and evidence claims (which require the relevant source and evidence from the ASL repository). `.github/workflows/ci.yml` runs the verifier in this repository; that is fixture conformance, not a claim that any third-party or production CI system adopts, endorses or depends on ASL.
