# ASL Conformance Kit

This repository contains public conformance artifacts for the Agent Safety Layer (ASL). It is intentionally separate from the ASL implementation repository and does not include the ASL source tree or test suite.

## Verify the conformance vectors

Requires Python 3.11 or later. The verifier uses only the Python standard library:

```bash
python conformance/verify_vectors.py
```

Expected result for the vectors in this revision: `checked 45 vector cases, 0 failures`.

This command verifies the language-neutral fixtures in `conformance/vectors/`. It does **not** rerun the ASL test suite, regenerate the reports, or independently reproduce the benchmark and gate measurements described by the bundled reports.

## Repository contents

- `conformance/vectors/` — canonicalization (RFC 8785), hashing, token, audit, attestation, and boundary protocol fixtures. Test keys in these fixtures are explicitly fake and are not production credentials.
- `conformance/verify_vectors.py` — standalone standard-library verifier for those fixtures; it does not import ASL.
- `conformance/benchmarks/` — public benchmark payload bundles and associated receipts.
- `docs/` — copies of selected ASL reports and documentation, including the public benchmark report, invariants, limits, and threat model.

The signed evidence report, boundary/ceiling receipt, and kernel-confinement notes are not published in this revision. They were withdrawn on 2026-10-30 pending regeneration; no containment-level or completeness claim is made here.

The ASL implementation, its test suite, evidence-generation scripts, and raw gate inputs belong in the [ASL source repository](https://github.com/Raja549h/helper), not in this kit. This repository’s reports and documentation may refer to those external implementation files to identify how a claim was tested; those links do not mean the files are included here.

## Important limits on report verification

The bundled benchmark reports identify their receipt algorithm as HMAC-SHA256 (or HS256). HMAC uses a shared secret; without a public verification key, a reader cannot independently authenticate those report signatures. The standalone vector verifier does not verify report or benchmark-receipt signatures. Do not treat the bundled HMAC values as publicly verifiable signatures or as independent certification.

The reports are snapshots copied from the ASL project. Their measurements are not regenerated by this kit, and this repository does not contain all raw inputs needed to reproduce every reported number. Consult the linked source repository and the evidence artifacts for the corresponding revision before relying on a measurement.

## Scope

This kit is a protocol-fixture and report-publication repository, not a distributable ASL implementation, a complete test environment, or an independent security assessment. It contains no ASL source or tests. Reviewers should distinguish vector conformance (which can be checked here) from implementation behavior and evidence claims (which require the relevant source and evidence from the ASL repository). Conformance is checked by automated CI test suites, not by production CI/CD.
