# Conformance Kit Status

This repository publishes ASL conformance artifacts. It is not the ASL implementation repository and does not contain ASL source code or the ASL test suite.

| Artifact | Status | What can be verified here |
|---|---|---|
| Language-neutral protocol vectors | Included | Run `python conformance/verify_vectors.py`; the current set reports 45 cases and 0 failures. |
| Standalone vector verifier | Included | Standard-library-only Python script; it does not import the ASL package. |
| Public benchmark bundles and receipts | Included | The bundles and receipt files are available for inspection. This verifier does not validate their signatures or rerun the benchmark. |
| Evidence, boundary, invariant, and limit documents | Included as snapshots | These documents describe results and link to the source project. Their numbers are not regenerated by the vector command. |
| ASL implementation and full test suite | Not included | See the [ASL source repository](https://github.com/Raja549h/helper); reproducing implementation-level claims requires the relevant source and evidence from that project. |
| Public verification of HMAC report signatures | Not provided | HMAC uses a shared key. This kit has no public-key verifier for the bundled HMAC/HS256 reports; readers cannot authenticate those signatures with this kit alone. |
| Independent security assessment or certification | Not provided | Vector conformance is not an independent audit, certification, or proof of real-world containment. |
