# Conformance Kit Status

This repository publishes ASL conformance artifacts. It is not the ASL implementation repository and does not contain ASL source code or the ASL test suite.

| Artifact | Status | What can be verified here |
|---|---|---|
| Language-neutral protocol vectors | Included | Run `python conformance/verify_vectors.py`; the current set reports 45 cases and 0 failures, and the command exits non-zero if the count is anything other than 45 or a vector file is malformed. |
| Standalone vector verifier | Included | Standard-library-only Python script; it does not import the ASL package. |
| Public benchmark bundles and receipts | Included | The bundles and receipt files are available for inspection. The verifier authenticates any **v2** receipt against `conformance/verifier_public_key.json`; the five receipts published here are v1 HMAC-only, so it reports them as not publicly verifiable and reruns nothing. |
| Invariant, limit, and threat-model documents | Included as snapshots | These documents describe the design and its limits and link to the source project. Their numbers are not regenerated by the vector command. |
| Signed evidence, boundary/ceiling, and kernel-confinement documents | Not included in this revision | Withdrawn on 2026-10-30 pending regeneration; no containment-level or completeness claim is made here. |
| ASL implementation and full test suite | Not included | See the [ASL source repository](https://github.com/Raja549h/helper); reproducing implementation-level claims requires the relevant source and evidence from that project. |
| Public verification of report signatures | Provided for **v2 only** | A receipt carrying `receipt_format_version: 2` and `receipt_ed25519` verifies against `conformance/verifier_public_key.json` with no shared secret. v1 receipts are HMAC-SHA256: they need the shared key, which this kit does not have, and the verifier labels them *not publicly verifiable* instead of claiming to check them. |
| Kit license, advisory contact and provenance | Included | `LICENSE` is the ASL license copied from the helper revision, `SECURITY.md` names the disclosure address (`rajtulshan3@gmail.com`, the same maintainer the implementation repository names) and the private-advisory flow, and `SOURCE_COMMIT` names the helper commit these artifacts mirror. `scripts/check_conformance_drift.py` compares `conformance/` against that revision and exits 1 on drift. `.github/workflows/ci.yml` runs the verifier on `push` and `pull_request` — **NOT VERIFIED LOCALLY, needs CI/manual check**: no Actions run for this repository has been observed from this host. |
| Independent security assessment or certification | Not provided | Vector conformance is not an independent audit, certification, or proof of real-world containment. |
